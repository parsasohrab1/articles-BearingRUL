# Business Requirements Specification – BearingRUL

| ID | Requirement |
|----|-------------|
| BR-1 | Derive a bearing health index from raw vibration snapshots. |
| BR-2 | Raise an early alarm with a threshold set from the early-life behaviour of the fleet, and report the lead time before failure. |
| BR-3 | Estimate the remaining useful life with an extrapolation of the health index, and report how reliable it is. |
| BR-4 | Report results per failure event; only four failure events exist in the data, so no statistical claim is made. |

Out of scope: fault-type diagnosis, other bearing data sets (FEMTO, CWRU), online deployment.
